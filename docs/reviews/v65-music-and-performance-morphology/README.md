# V65 music-and-performance-morphology funnel

This directory records the fixed 50-surface, two-reviewer funnel governed by ADR-0089.
It considered two genitive/dative forms for each of 25 existing music and performance
concepts. Forty-eight sense-qualified forms passed both reviews. `notei` and `notelor`
were rejected because _notă_ ordinarily denotes not only a musical pitch or notation
sign, but also a school grade, a written memo, an annotation, a bill, a diplomatic
communication, and a characteristic nuance or trait. No quota applied.

Qualifiers such as `formațiilor muzicale rock`, `scenei principale de festival`,
`albumelor muzicale`, and `acordurilor muzicale` bind the accepted surfaces to one
existing musical sense. The accepted forms add no concept or sense. They remain exact
aliases consumed only by typed Contexto input and otherwise-legal Lanț hops. The wave
preserves projections, graph topology, game records, ranking rows, the frozen derived
payload, session bounds, accounts, frontend, privacy, and deployment state.
