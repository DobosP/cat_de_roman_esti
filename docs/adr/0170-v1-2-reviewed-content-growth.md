# ADR-0170: V1.2 reviewed lexical growth and native installed-authority reconstruction

- Status: accepted; integrated gates and assembled review GREEN; local landing17f7da1
- Date: 2026-10-06

## Context

The owner requested internet-researched synonyms and specific new graph links, creative
candidate discovery, unchanged quality/tooling considerations and consecutive content versions
until stopped. Native V1 builders retain immutable historical source/review bindings, but
could not reconstruct a separately reviewed new installed version. The exploration audit
also depended on the old installed snapshot, preventing review of a matching prospective
world after shared-graph changes. These are concrete installation obstacles, not reasons
to weaken review or rewrite historical evidence.

## Decision

Bound V1.2 to four independently reviewed synonym families and one existing-node relation.
Accept 22 distinct normalized input forms for ascensor/Lift, tomată/Roșie, scripcă/Vioară
and prăvălie/Magazin; preserve their existing identities and repeated-attempt behavior.
Link Cărare/Potecă bidirectionally only in their existing pedestrian-path senses, with
strength0.95 as an editorial estimate. Do not merge IDs, grant new target approval,
claim new rounds, or install ambiguous/redundant R1 forms. Retain every hold and source limit.

Use the supported rollback-protected graph transaction, then fresh native candidate,
independent semantic/final review and current source/runtime audit rails. Immutable V1
source and archives remain exact. A separately pinned installed-authority manifest binds
sequential source ancestry, exact candidate/review/proposal/audit/final documents and artifact
SHA; default checks reconstruct every registered current rail through the existing strict
review and deep installed-state checks. A pin alone never grants approval.

Exclude only the new manifest and its strictly generated metadata-only pin file from the
runtime audit to avoid self-reference. Check their exact bytes separately, bind them into
transaction readsets and recheck them before/after verification. Protect all runtime inputs
and both authority files from operator outputs; reject stale, missing, tampered, duplicate,
nonsequential, symlinked or replaced evidence. Preserve all previously audited runtime inputs.

Validate the whole current graph before prospective exploration auditing. Overlay that
validated graph and independently reviewed world on a freshly decoded immutable serving
baseline inside the private audit process, then replay all goal modes, recipes, histories
and saved prefixes. This does not install content or relax current source export validation.

Freeze actual runtime/code/source/export before fresh post-installation audits and final
judgments. Retain original HTTP vectors and independently capture/review current reference
responses when source identities change. Preserve existing records, recipe mechanics,
resource bounds, privacy and deterministic selection; report graph/forms/rounds separately.

Continue sequential V1.x content waves after each fully verified local landing, using the
same chat heartbeat and repository content skill until the owner stops or pauses the loop.
Each wave has a finite research scope and independent quality gates. Push and deployment
retain their separate authorization boundaries.

## Evidence and consequences

Evidence is in [the V1.2 review](../reviews/v1-2-content-growth/README.md) and the durable
candidate pool. The graph changes improve typed input coverage and one honest direct hop;
Cald rank ripple is measured and disclosed. Automated checks do not establish human enjoyment.
The continuation loop reuses incomplete work, preserves research holds and cannot advance a
version merely because a candidate is authored or a pin changes. The independent assembled review accepted the version; local main landing is17f7da1.
