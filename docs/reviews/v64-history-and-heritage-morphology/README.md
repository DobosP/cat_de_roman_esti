# V64 history-and-heritage-morphology funnel

This directory records the fixed 50-surface, two-reviewer funnel governed by ADR-0088.
It considered two genitive/dative forms for each of 25 existing history and heritage
concepts. Forty-eight sense-qualified forms passed both reviews. `frontului` and
`fronturilor` were rejected because _front_ ordinarily denotes not only a military
battle line, but also a line formation, an organized political or social grouping, a
mining work face, an architectural frontage, a meteorological boundary, and a physical
wavefront. No quota applied.

Qualifiers such as `bătăliei istorice`, `domnitorilor medievali`, `tratatelor
diplomatice`, and `independențelor naționale` bind the accepted surfaces to one existing
historical sense. The accepted forms add no concept or sense. They remain exact aliases
consumed only by typed Contexto input and otherwise-legal Lanț hops. The wave preserves
projections, graph topology, game records, ranking rows, the frozen derived payload,
session bounds, accounts, frontend, privacy, and deployment state.
