# ADR-0188: Live Home baseline selector equivalence and explicit diagnostics

Date: 2026-10-10
Status: accepted implementation source; only LCP/INP comparison direction partially superseded by ADR-0190; full qualification pending

## Decision

Permit only the six ordered Home card selectors and footer selector described by the immutable original baseline to use their reviewed current aliases. Verification must first bind the actual clean/full or explicit owner-shell context, source bytes and served image identity, then observe unique native buttons, exact computed accessible names, unchanged order, the same original/current DOM nodes and unchanged native footer text. Historical reports and synthetic declarations cannot authorize aliases. Every rule ID, impact, ordered target, other route and unknown selector remains strict.

Retain separate outcomes for the live witness, Axe fingerprint, all nine exact original PNG comparisons and all four existing LCP/INP predicates, even after an earlier comparison fails. Any failed predicate still returns failure. Keep the original five contexts, callbacks, CDP throttling, seeded actions, waits, real pagehide finalization, medians and absolute max(10%,50ms) tolerance. Do not repin the original baseline or change game, font, preload, budget or browser-case behavior.

An explicit owner-diagnostic mode may run against the wrapper-owned image in its real loopback namespace. It retains fresh private source/image/Home/comparison evidence and bounded browser cleanup, without creating a full receipt. Only this mode adds LCP element, resource and font attribution. Its unmeasured overhead is labelled as potentially affecting timings; normal capture, original-capture and verify keep the original metric/event acquisition and shape.

## Context and consequences

Actual full6ebc completed900/900 cases and retained byte-identical nine PNGs, but baseline verification stopped on Home Axe selector strings before its PNG/vitals assertions. A later genuine a572 owner-shell witness proved all six exact native node/name/order joins and the unchanged footer. Supplemental LCP readback is red under the unchanged predicate; neither observation proves a cause, a new accepted timing baseline or fastest-possible performance.

The first e27 source packet is preserved with overall acceptance withheld: its extra attribution observer was unconditional. Separately closed ce807b1 restricts all extra work and output to owner-diagnostic; parent and independent source review accepted the correction. Forty meaningful synthetic refusal/comparison controls are authored NOT RUN. Actual managed targeted checks, source-stable captures and full validation remain required. Source6 installed authority/pin reconstruction, red route budgets, E3, M0/M1, KIT_BUMP, real Samsung and dependent M2/S0b/other applications remain separate obligations. No previous ADR body is superseded or edited.
