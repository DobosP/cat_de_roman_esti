# ADR-0158: Prepare V1 for mixed-age phone and desktop testing

Date: 2026-09-23
Status: accepted; partially amended by [ADR-0159](0159-v1-0-1-testing-hardening.md) (lobby label, word-grid reflow)

## Context

The owner requested the next internal wave (V100) as a stable testing release named
V1, covering interface friction, current board quality and reconsideration of held
content. The intended testers are mixed ages using phones and desktop browsers.
V99 is the baseline; production publication remains a separate action.

## Decision

Expose V1 in the lobby and use package version 1.0.0. Put descriptive game choices
before daily progress. Preserve daily intent when navigating from the circuit, then
present an explicit daily start action while retaining saved-round recovery. Make
help directly accessible, remove empty option disclosures, label remaining mistakes
accurately, and put replay before copying a result. Reflow word cards for 320 px
with enlarged text. Guard browser storage access during startup; permit automatic
chunk-recovery reload only with a persisted loop guard, and offer explicit recovery
when a game route cannot load. Keep an error beside its retry control, and render the
authoritative Lanț position immediately without waiting for a decorative exit animation.

Retain the six mechanics and anonymous access. Existing score, session, history,
request-size and discovery-book bounds remain unchanged. Inspiration comes from
objective-first puzzle interfaces and optional local help, with source/access details
in the release review; no external implementation or artwork is copied.

Apply the seven independently reviewed factual corrections through an exact-record,
review-bound transaction. Preserve all 180 KG puzzles and fail the transaction if
they no longer validate. Review resulting graph effects before refreshing dependent
artifacts; do not weaken provenance or recipe snapshot checks.

Keep stored approved content as historical evidence while excluding precisely reviewed
weak boards from new selection in the bundled release. The release reserve covers four sparse Cald targets,
four ambiguous or mirrored Conexiuni boards, twelve one-opening Alchimie challenges,
and three quick boards with a misleading Latin-substrate explanation. The bounded,
digest-pinned reserve applies before every quick selection path, including fallback.
It matches exact board definitions rather than excluding an entire source family.
Explicit custom pack/KG overrides retain their existing unranked compatibility
behavior; those development inputs are outside the bundled testing release.
This partially supersedes ADR-0054 only for this explicit selection exclusion; its
preferred threshold, category balance, repeat avoidance and starter rules remain.

Reconsider held content individually. Correct captions may remove an explanation
blocker but confer no approval: the existing fresh dossier, independent analyst and
verifier, and strict promotion gate remain mandatory. Preserve rejected records and
research pools. No addition quota or general relaxation of quality criteria applies.

Preserve the exact original bytes of the V1 evidence archive in Git, including
reviewed native-generator CRLF records. Archive-specific attributes disable automatic
line-ending conversion and recognize CRLF while retaining actual whitespace checks.
Changing approved evidence bytes requires renewed bindings rather than silent normalization.

## Consequences

The test release favors clear play and defensible explanations over inventory growth.
Inventory and selectable counts must be reported separately. Deterministic scans,
editorial samples, browser emulation and human observations must remain distinct.
The Romanian tester guide provides an all-six-game session and concrete feedback
format. Technical checks do not establish enjoyment or physical-device acceptance.
