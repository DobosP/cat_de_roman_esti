# V63 film-and-television-morphology funnel

This directory records the fixed 50-surface, two-reviewer funnel governed by ADR-0087.
It considered two genitive/dative forms for each of 25 existing film and television
concepts. Forty-eight sense-qualified forms passed both reviews. `rolului` and
`rolurilor` were rejected because _rol_ ordinarily denotes not only a performed
character, but also a function or duty, a court docket, a fiscal or maritime register,
and a rolled collar. No quota applied.

Qualifiers such as `serialului dramatic de televiziune`, `trailerelor de film`,
`camerei video profesionale`, and `operatorilor profesioniști de imagine` bind the
accepted surfaces to one existing screen-production sense. The accepted forms add no
concept or sense. They remain exact aliases consumed only by typed Contexto input and
otherwise-legal Lanț hops. The wave preserves projections, graph topology, game
records, ranking rows, the frozen derived payload, session bounds, accounts, frontend,
privacy, and deployment state.
