# ADR-0110: Borrow reviewed direct fruit-preserve feedback for Gem

- Status: accepted
- Date: 2026-09-06

## Context

V78 deferred Clătite because accepted Gem guesses were frozen while Dulceață was
hot. Gem borrowed Miere through Contexto's projection table. V79's first global
Dulceață substitution repaired Clătite but made Gem warm for unrelated savory
boards. A one-hop-only alternative would still inherit a weak seasonal Socată edge.
Independent factual and impact reviews rejected both unrestricted alternatives.

## Decision

Retain every existing projection term and its default anchor. Give only Gem an
authored local feedback policy: borrow Dulceață when it is the target itself or
when a directed non-distractor Dulceață→target edge has strength at least 0.60.
Otherwise retain the original Miere feedback. The reviewed graph has exactly six
qualifying targets: Dulceață, Papanași, Magiun de Topoloveni, Conserve de iarnă, Clătite and Fruct.
Socată's generic seasonal edge is 0.45 and does not qualify. The numerical floor
bounds this individually reviewed neighborhood; it is not automatic semantic
approval for future edges, terms or graphs.

Use one effective-anchor helper for accepted guesses and typo suggestions.
Preserve Gem's normalized surface, synthetic ID, ingredient domain and penalty
of one. Gem cannot win a Dulceață round or reveal its private anchor; direct
Dulceață still wins normally. Miere-secret suggestions retain their existing
filter, while Dulceață-secret suggestions also exclude projected Gem.

The source checks, rejected experiment, exact neighborhood, public API sweep and
regressions are archived in [the V79 review](../reviews/v79-gem-feedback/README.md).

## Consequences

Gem improves for Papanași, the only affected currently approved Contexto target,
and for the five other qualifying fixed targets. All other 206 approved targets
retain exact Gem feedback. Clătite's corrected Gem path enables a fresh review,
not an automatic promotion. Cozonac retains the original cold Gem/Nucă routes;
Nucă/Alună, Unt/Miere and the earlier bread problem remain separate questions.

All 473 original projection terms, KG/pack/ranking/mobile artifacts, frozen
boards, selection, score rules and session bounds remain exact. The helper uses
an existing direct-edge lookup and adds no BFS, per-session field or cache.
There is no new alias, recipe, Lanț move, frontend asset or public rollout.
