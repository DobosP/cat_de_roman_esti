# V66 science-and-discovery-morphology funnel

This directory records the fixed 50-surface, two-reviewer funnel governed by ADR-0090.
It considered two genitive/dative forms for each of 25 existing science and discovery
concepts. Forty-eight sense-qualified forms passed both reviews. `curentului` and
`curenților` were rejected because _curent_ ordinarily denotes moving air, flowing
liquid, and electric current. Singular `curentului` additionally serves the ideas/opinions
and literary/artistic-movement senses. No quota applied.

Qualifiers such as `laboratoarelor de cercetare`, `experimentelor controlate`,
`virusurilor biologice`, and `rachetelor spațiale` bind the accepted surfaces to one
existing scientific sense. The accepted forms add no concept or sense. They remain
exact aliases consumed only by typed Contexto input and otherwise-legal Lanț hops. The
wave preserves projections, graph topology, game records, ranking rows, the frozen
derived payload, session bounds, accounts, frontend, privacy, and deployment state.
