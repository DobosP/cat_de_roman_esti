# Core gate contract for a consumer

The assigned implementation worktree is the only mutable repository. Product
builds, tests and lockfile generation use the pinned Linux wrapper. Read current
PROGRAM, status, request files and the self-contained twelve-section ExecPlan.
Read actual HEAD/status separately and pass literal SHA to the absolute gate.sh.
Worker targets are unit/full/gen/deps/build/image and named authorized captures;
owner owns trust/toolchain/kit sync/release/landing. No host npm/go/task install,
Docker socket in runner, Full access, global policy changes or real credentials.
Gate files change only in justified GATE-CHANGE commits; wait for parent pin.
Keep mandatory checks, CSP, accessibility, reduced motion, focus, privacy and child
safety intact. No fake results, measurements, skips or owner sign-off. Unit may
skip pg-live only no-dsn; full never skips. Reading comfort is self-paced only.
