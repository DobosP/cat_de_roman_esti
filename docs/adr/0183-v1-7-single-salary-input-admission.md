# ADR-0183 — Admit the single V1.7 salary input to supported qualification

Status: Accepted
Date: 2026-10-08

## Context

The ordinary employee-pay word leafă is unknown in the qualified Source6 game.
Current original DOOM/DLR evidence distinguishes its ordinary pay sense from marked
regional-tool and older-pay readings. V50 previously rejected the same surface and

## Decision

Admit only singular leafă, normalized leafa, to existing n_v4soc_salariu for the
supported V1.7 adoption process, after exact independent final factual and quality
acceptance. Treat exactly this literal as reconsidered in the current wave's inherited
70-surface deferred vector, retaining the other 69 values, order and measured behavior.
Original V50/V72/BLOCKED sources, dictionaries, review records, shared importer gate
and thresholds remain unchanged. Original all-seven assertions remain meaningful
against genuine Source6 archives, with separate current-input checks.

A global bare alias supplies an ordinary employee-pay default; it does not filter
intent or establish equivalence for every rare regional-tool, mercenary or income sense.
This decision admits one genuine synonym family and one stored form, not a concept,
edge, target, curated round, inflection set or eligible/preferred-pool increase.

## Qualification boundary

helper evidence passed. Source7 and live content have not been installed. Adoption
uses supported transactions/native builders with exact reviewed Source6 parent and
all ancestry archives. Actual installed history/current metadata/whole-byte inverse,
new source/catalogue/reference/corpus/current authority bindings, frozen-runtime
