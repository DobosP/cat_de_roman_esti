# ADR-0201: Adopt core-v1.10 consumer contracts

Date: 2026-10-13
Status: Implemented on the feature branch; clean qualification pending
Authority: PROGRAM E8/E10; core ADR-0028; Cat M2 review follow-ups

## Decision

Adopt the published core-v1.10 kit through kit:sync and deps. The consumer uses
its delivered canonical CSS layer order; remove the temporary layers.css shim.
Bind the complete nine-file bootstrap runtime closure, including csp-measurement,
to the exact release archive. Refresh its wrapper template and generated lock.

Declare frozen CSP evidence with the original receipt, archive and manifest pins.
The kit independently checks every frozen member, actual entry, eager assets and
nonce identity; Cat retains its exact nine-page and live browser assertions.
All-current delivery omits the descriptor and both frozen observation fields.
A completed generated legacy tree has exactly the receipt's thirty files: remove
only its verified empty regular scaffold after complete member verification.
The tracked unbuilt source scaffold and original frozen archive remain unchanged.

Retired original/normalized style planner requests fail by name before executing
commands or creating planner artifacts. Historical request parsing and evidence stay.
No budgets, browser assertions, baselines or game content change.

## Validation

[Generator records](../reviews/gui-core-v110-adoption/generators.json) bind actual
commands, source identity, outcomes and result hashes. Re-audit the native source
signature after the generated Go module pin; do not automatically refresh it.
[Independent source review](../reviews/gui-core-v110-adoption/source-review.json)
and [focused checks](../reviews/gui-core-v110-adoption/focused.json) pass. Clean
unit/full still precede acceptance.
