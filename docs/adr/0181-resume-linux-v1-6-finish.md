# ADR-0181 — Resume Linux V1.6 qualification and the content loop

Date: 2026-10-07
Status: Accepted — human-authorized Linux continuation

## Context

After inspecting the Windows checkpoint a1f0079 and the finite remaining V1.6
verification work, the human requested: “Okay, continue, start the loop and work
on this. Work on iterations.” Existing V1.6 aliases, Source6, exact accepted
runtime and earlier completed gates are already present. Windows/WSL supervision
work and its incomplete/failed campaigns remain historical evidence.

## Decision

Resume the existing codex/content-v1-6 Linux task and sequential content loop,
superseding ADR-0180's stop. Finish V1.6 before the next version. Reuse only exact
bound valid evidence, qualify the minimal demonstrated Linux runner gap, and run
all nineteen remaining content-rail cases plus final CLI/vet/documentation checks
under fresh independently reviewed finite admissions. Failed clocks are immutable;
a materially different Linux compiled-binary campaign has one new fixed window
and cumulative baseline, without resource, assertion or review relaxation.

The original chat orchestrator owns any green local main landing and the previously
explicitly authorized V1.6 origin/main publication. Workers never merge or push.
No deployment, provider or PostgreSQL activation is authorized. Pool records become
integrated only after actual green landing. Subsequent versions retain their full
independent content gates and stop/pause remains controlled by the human.
