# V61 home-care-and-maintenance-morphology funnel

This directory records the fixed 50-surface, two-reviewer funnel governed by ADR-0085.
It considered two genitive/dative forms for each of 25 existing home-care and maintenance
concepts. Forty-eight sense-qualified forms passed both reviews. `cheii` and `cheilor`
were rejected because _cheie_ ordinarily denotes not only a door or lock key, but also
an explanation or cipher key, several tools, a musical clef, an architectural keystone,
or a mountain gorge. No quota applied.

Qualifiers such as `prosopului de baie`, `bureților pentru vase`, `cuiului de atelier`,
and `furtunurilor pentru grădină` bind the accepted surfaces to one existing household
or maintenance sense. The accepted forms add no concept or sense. They remain exact
aliases consumed only by typed Contexto input and otherwise-legal Lanț hops. The wave
preserves projections, graph topology, game records, ranking rows, the frozen derived
payload, session bounds, accounts, frontend, privacy, and deployment state.
